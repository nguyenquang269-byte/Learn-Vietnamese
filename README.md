## Noihay - Vietnamese Learning Platform for Kids (V2.1 "Macaron Edition")

Noihay is a premium, gamified educational platform designed to help children learn Vietnamese (pronunciation, spelling, and vocabulary) through interactive, high-fidelity games.

### ✨ Key Features
- **Unified Game Modal**: An immersive, single-page experience for lessons and games.
- **Phù thủy sửa âm**: Real-time voice-controlled pronunciation game (Web Speech API).
- **Khỉ con leo núi**: Vertical-climbing spelling game with 3D-effect UI.
- **Macaron/Pastel Design**: A soft, "mát mắt" aesthetic tailored for children.
- **Night Mode ("Sleepy Mode")**: A gentle midnight theme for late-night learning.
- **Dino Trail**: Interactive progress tracking with rewards.

### 🚀 Technical Stack
- **Framework**: ASP.NET Core 9.0 (Razor Pages)
- **Database**: In-Memory (EF Core) for easy demonstration.
- **Frontend**: Vanilla CSS (Custom Design System), JavaScript (Game Logic).
- **Architecture**: 3-Layer (BusinessObject -> Services -> Web).

### 🛠️ Getting Started
1. Clone the repository.
2. Navigate to `Noihay.Web`.
3. Run the application:
   ```bash
   dotnet run --no-launch-profile
   ```
4. Access at `http://localhost:5000`.
